1920 gangster simulator built around immediate, bounded chains of cause and effect. Actions change people, districts, businesses, and police attention. Every outcome needs a clear narrative reason, and every scenario needs a deterministic test.

The game is set in 1920 and all in-game money is denominated in 1920 U.S. dollars. Never use modern or inflation-adjusted dollar figures as in-game amounts, if a value needs to "feel" like a modern number for playtesting purposes, convert it explicitly and label it as such; it must never ship as an in-game value.

When making changes to money related stuff read economic_anchors.md what to take into account
